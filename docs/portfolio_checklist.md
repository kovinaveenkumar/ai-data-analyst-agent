- [ ] `python -m scripts.check_setup` shows all OK
- [ ] `python -m pytest` passes locally
- [ ] App answers the six example questions
- [ ] `python -m evaluation.run_eval --compare` run; results saved
- [ ] Read the FAIL cases; improve business rules or examples; rerun (keep the test set unchanged)

- [ ] API spending limit set
- [ ] Demo video (2 minutes) uploaded
